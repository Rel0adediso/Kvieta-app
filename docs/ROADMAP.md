# Kvieta roadmap

**Aktif hedef:** Kvieta v1.0.0 release preparation.

## Windows v1.0

- Complete installation, upgrade, recovery and uninstall acceptance tests on Windows.
- Publish the Windows x64 community installer and its verification files once release checks pass.
- Keep support, known limitations and upgrade guidance up to date.

## After v1.0

- Improve Windows compatibility and usability based on user feedback.
- Continue optional Android companion development, including authorized family policy management and command status.
- Extend local insights and focus tools while preserving privacy and accessibility.

See the [release notes](RELEASE_NOTES.md) for the development history and [security model](SECURITY.md) for the supported protection boundary.
